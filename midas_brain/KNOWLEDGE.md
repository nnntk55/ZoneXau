# Midas Knowledge Pack — อินดิเคเตอร์สำหรับ XAUUSD

คู่มือปฏิบัติการสำหรับ verdict: ทุกอินดิเคเตอร์มี "บอกอะไร / ใช้ยังไง / กับทองต้องระวังอะไร"
กฎแม่: อินดิเคเตอร์คือเครื่องช่วยตัดสิน ไม่ใช่เครื่องสั่ง — confluence ≥2 แหล่งถึงมีน้ำหนัก

## 1. เทรนด์ (Trend)

### EMA System (แกนหลักของบ้านนี้)
- **M5**: EMA10/20/200 — เทรนด์ระยะสั้น ราคาเหนือทั้งสาม = เทรนด์ขึ้นชัด / ต่ำกว่าทั้งสาม = ลงชัด / ไขว้ = ขาดทิศ
- **H4**: EMA50/100/200 — โซนแนวรับต้านไดนามิก ราคาลอยห่าง EMA50 มาก = เทรนด์แข็ง (และเสี่ยง mean reversion)
- กฎนิน: ระยะห่างราคาถึงแนวตรงข้าม <$20 = ปลายเทรนด์ เข้าช้า
- EMA10 ตัด EMA20 (M5) = สัญญาณโมเมนตัมระยะสั้น; ตัดบน H1/H4 = สัญญาณเปลี่ยนเฟสใหญ่กว่า

### Market Structure (สำคัญกว่าอินดิเคเตอร์ทุกตัว)
- HH/HL = เทรนด์ขึ้น / LH/LL = ลง / หลุดโครงสร้าง = สัญญาณแรกของการเปลี่ยนเฟส
- ทองชอบ sweep liquidity: หลอกทะลุ high/low เดิมก่อนกลับตัว — ทะลุแล้วปิดกลับ = สัญญาณสวนแรง

## 2. โมเมนตัม (Momentum)

### StochRSI (ตัวที่ระบบนินใช้)
- %K ตัด %D ในโซน <20 (oversold) = จุดซื้อ pullback / >80 = จุดขาย
- %K>50 = โมเมนตัมขาขึ้น / <50 = ขาลง — ใช้ยืนยัน bias ได้ ไม่ใช่เข้าไม้ตรงๆ
- ทอง: StochRSI M5 ติดโซนสุดขั้วนานในตลาดเทรนด์แข็ง = "ติดเพดาน" อย่าสวน

### RSI
- >70/​<30 = ขั้ว แต่ในทองเทรนด์แข็ง RSI ค้าง 70+ ได้เป็นวัน — อย่าฟันธงกลับตัวจาก RSI เดี่ยว
- Divergence (ราคา HH แต่ RSI LH) = เทรนด์อ่อนแรง — สัญญาณเตือนก่อนกลับตัว ไม่ใช่จุดเข้า

### MACD Histogram (5,13,9 — สเปก C# ของนิน)
- histogram ขยาย = โมเมนตัมเพิ่ม / หด = อ่อนแรง — ใช้วัดแรงเทรนด์ไม่ใช่หาจุดเข้า

## 3. Fibonacci

- Retracement ที่ทองเคารพบ่อย: **0.382 / 0.5 / 0.618** (0.5-0.618 = "golden pocket")
- ใช้หลังขาเทรนด์ชัด: ลาก swing low→high (ขึ้น) เพื่อหาโซน pullback
- Fib ไม่ใช่แนวมหัศจรรย์ — ใช้เป็น "โซนเฝ้า" ร่วมกับ EMA/แนว S/R เดิม = confluence
- Extension 1.272/1.618 = เป้าไม้ยาวเมื่อเทรนด์ต่อ

## 4. Volume Profile (โครงสร้าง volume ตามราคา)

- **POC** (Point of Control) = ราคาที่ volume หนาแน่นสุด — แม่เหล็กราคา/โซนแย่งกัน
- **VAH/VAL** (Value Area 70%) = โซนที่ตลาดยอมรับราคา; นอก VA = ราคาเคลื่อนเร็วผ่าน
- **HVN** (volume สูง) = แนวหนัก ราคาช้าผ่าน / **LVN** (volume บาง) = ช่องว่าง ราคาทะลุเร็ว
- ใช้กับทอง: ช่วงเอเชีย volume บาง VP ไม่ค่อยนิ่ง — อ่านจาก session London/NY แม่นกว่า
- ถ้าไม่มีข้อมูล VP จริงจากโบรก: ใช้แนว swing/volume-at-price จากแท่งเป็น proxy อย่าเดาตัวเลข

## 5. โซน (Zone — หลักของนิน)

- **โซนไม่ใช่เส้น** — แนวรับ/ต้านคือ "พื้นที่" กว้างหลายเหรียญ ไม่ใช่เส้นบางเส้นเดียว: ห้ามตัดสินจากการแตะจุดเดียว
- **โซนไดนามิก** = EMA50/100/200 บน H4 ของบ้านนี้ — เคลื่อนตามราคา ไม่ตายตัวเหมือนเส้นวาดมือ
- **กฎ $20**: buy ต้องมีที่ว่างถึงแนวต้าน >$20 / sell ต้องมีที่ว่างถึงแนวรับ >$20 — ใกล้กว่านั้นคือเข้าปลายเทรนด์ กำไรน้อยความเสี่ยงเต็ม
- **ไม่มีแนวตรงข้าม = ทางโล่ง**: ตลาดพุ่งยาวราคาลอยห่างทุก EMA = ไม่มีเพดานให้วัด ผ่านเงื่อนไขโซน
- **รีเทสโซน**: ทะลุแล้วย้อนมาแตะโซนเดิมจากอีกฝั่ง = โอกาสดีที่สุดของโซน (support กลาย resistance กลับกัน) — รีเทสแล้วเด้ง = โซนยังทำงาน / หลุดผ่าน = โซนตาย
- **โซนมีอายุ**: ยิ่งโดนทดสอบบ่อยยิ่งอ่อน — โซนที่เด้งมา 3-4 รอบโดยไม่ทำ high ใหม่ = กำลังจะแตก
- **sweep liquidity**: ทองชอบวิ่งไปเก็บ stop เหนือโซนก่อนดีดกลับ — high/low เก่าที่โดนแหย่นิดแล้วกลับตัว = สัญญาณสวนแรง
- **การอ่านผลโซน**: แตะ→เด้งห่าง ~0.6% = โซนทำงาน / ทะลุ >0.3% แล้วไม่กลับ = โซนแตก / ไม่ชัดใน 24 ชม. = ไม่มีข้อสรุป
- **ทิศโซนกับเทรนด์**: เข้าตามเทรนด์ที่โซนเด้ง = คุณภาพสูง / เข้าสวนเทรนด์ที่โซน = เสี่ยงสูงสุด ต้องการ confluence เพิ่ม

## 6. Volatility

### ATR
- วัดช่วงแกว่งจริง — ATR M5 ~$2-4 / H1 ~$5-10 (ยามตลาดปกติ)
- ใช้ปรับความกว้าง SL/TP ตามความผันผวน และแยก "การเคลื่อนปกติ" จาก "การเคลื่อนผิดปกติ"
- ATR พุ่ง 2-3 เท่าของค่าเฉลี่ย = ข่าว/เหตุการณ์ — ระวังสเปรดและสลิปเพจ

## 7. อื่นที่ควรรู้

- **VWAP**: ราคาเฉลี่ยถ่วง volume รายวัน — ราคาเหนือ VWAP = buyers คุมวันนี้; ทองไม่มี centralized volume แต่ tick volume พอใช้เป็น proxy ได้

## 8. Bollinger Bands (20,2 — ละเอียด)

- **ส่วนประกอบ**: mid = SMA20, แถบบน/ล่าง = ±2 standard deviation — ครอบราคา ~95% ของเวลา
- **Squeeze (หด)**: แถบบีบแคบ = volatility หดตัวสะสมพลัง — เตรียมแตกแรง ไม่ทายทิศ แต่เตือนว่าการเคลื่อนใหญ่ใกล้มา; squeeze ยาวยิ่งแตกแรง
- **Expansion (ขยาย)**: แถบเปิดกว้าง = เทรนด์/ความผันผวนกำลังทำงาน — ตามแถบไปเรื่อยๆ ได้ในเทรนด์แข็ง (ราคา "เดินแถบ" walk the band)
- **แตะแถบนอก ≠ สัญญาณสวน**: ในเทรนด์แข็งราคาติดแถบบนได้ยาว — แตะแถบแล้วสวนคือหลุมคลาสสิก; ใช้สวนได้เฉพาะเมื่อตลาด range ชัดเจน + มี confluence (RSI oversold/โซน)
- **Rejection ที่แถบ**: แตะแถบนอกแล้วปิดกลับเข้าในทันที + โมเมนตัม divergence = สัญญาณย่อยกลับเข้า range
- **กลับเข้ากลาง (mean reversion)**: ราคาห่าง mid band มาก + แถบเริ่มหดกลับ = โมเมนตัมจบรอบ มักกลับมาหา mid band
- **กับทอง**: M5 ผันผวนหนักแถบจะขยายบ่อย — อ่าน squeeze/expansion บน M15/H1 แม่นกว่า; ข่าวแรงทำทะลุแถบทั้งสองฝั่งสลับ อย่าอ่านเป็นสัญญาณ

## 9. กฎการอ่านร่วม (Confluence Rules)

- เทรนด์ + โมเมนตัม + โซน ตรงกัน 3 ด้าน = คุณภาพสูงสุด
- อินดิเคเตอร์ขัดกัน = ตลาดไม่ชัด → verdict ควรเป็น neutral/mixed ไม่ใช่เลือกข้าง
- divergence โมเมนตัม + ราคาเข้าใกล้โซนสำคัญ = เตือนกลับตัว ไม่ใช่สัญญาณสวนอัตโนมัติ
- กฎนินเสมอ: ไม่มีตัวเลขจาก tool = บอกว่าข้อมูลขาด ห้ามเดา
